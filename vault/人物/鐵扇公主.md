# 鐵扇公主

**別名**:羅剎女、鐵扇仙、羅剎

**總出現次數**:97,**出場回數**:4 回

### 生平概述

[[鐵扇公主]]，又名[[鐵扇公主|羅剎女]]或[[鐵扇公主|鐵扇仙]]，為[[牛魔王]]之正妻，居住於翠雲山芭蕉洞。她手中持有能熄火、生風、下雨的神器芭蕉扇，具備強大的法力。

因[[孫悟空]]曾收服其子[[紅孩兒]]，[[鐵扇公主]]對[[孫悟空]]懷恨在心。當[[孫悟空]]前來借扇時，她不僅拒絕，更取出披掛與兩口青鋒寶劍，在翠雲山前與[[孫悟空]]激烈爭鬥。雖然她解數周密，但因[[孫悟空]]棒重且神通廣大，最終未能戰勝對方。

經歷多次交鋒與計謀博弈後，[[鐵扇公主]]先後被[[孫悟空]]變化的形象戲弄，包括吞食茶沫使其腹中受苦，以及被偽裝成[[牛魔王]]的[[孫悟空]]騙取真扇及口訣。最終在[[牛魔王]]被擒的情況下，[[鐵扇公主]]卸下妝飾，跪地磕頭，將芭蕉扇奉獻給[[孫悟空]]以助其成功，隨後捏碎扇子隱姓修行。

### 重要事蹟

*   **翠雲山初戰**：取出披掛和兩口青鋒寶劍，出門與[[孫悟空]]爭鬥至日落，因解數周密且[[孫悟空]]棒重，料鬥不過而退回。（第59回）
*   **一扇定勝負**：取出芭蕉扇，一扇陰風將[[孫悟空]]扇得無影無形，以此得勝回歸。（第59回）
*   **再戰失利**：再次與[[孫悟空]]戰鬥五七回合，見事勢不諧，取扇子扇[[孫悟空]]但[[孫悟空]]巍然不動，慌亂關門入洞。（第59回）
*   **腹中受困**：因口渴喝下藏有[[孫悟空]]茶沫的茶水，在[[孫悟空]]於其腹內做手腳時疼痛難禁，坐於地下叫苦並打滾。（第59回）
*   **被迫借扇**：面黃唇白，只叫[[孫叔叔]]饒命，情願將扇借與[[孫悟空]]；叫女童拿芭蕉扇執在旁邊，張口三次讓[[孫悟空]]出來。（第59回）
*   **誤放真身**：不知[[孫悟空]]已變回原身拿扇離開，連張三次叫叔叔出來。（第59回）
*   **醉酒泄密**：在醉酒狀態下向[[孫悟空]]透露了芭蕉扇變大的口訣。（第60回）
*   **怒斥欺騙**：發現[[孫悟空]]現出原形並騙走扇子後，氣得跌腳捶胸。（第60回）
*   **哭訴丈夫**：向趕回的[[牛魔王]]哭訴被[[孫悟空]]騙走扇子之事。（第60回）
*   **泣送假扇**：接過[[牛魔王]]（實為[[孫悟空]]所變）吐出的扇子，滿眼垂淚欲送扇子退兵。（第61回）
*   **跪献真扇**：在[[牛魔王]]被擒後，卸釵環脫色服，雙手捧扇子走出門，跪地磕頭，願將扇子奉承[[孫悟空]]成功。（第61回）
*   **乞求自新**：向[[孫悟空]]乞求歸還扇子，並表示悔之晚矣、願自新修身養命。（第61回）
*   **隱姓修行**：接過[[孫悟空]]還回的扇子，捏做杏葉兒噙在口裏，拜謝眾聖隱姓修行。（第61回）

### 人物關係

*   **配偶**：[[牛魔王]]（正妻）
*   **子女**：[[紅孩兒]]
*   **對手/仇家**：[[孫悟空]]（因紅孩兒之事懷恨，多次衝突）
