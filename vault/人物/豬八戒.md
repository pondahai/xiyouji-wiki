# 豬八戒

**別名**:八戒、悟能、豬悟能、老豬、呆子、天蓬元帥、豬剛鬣、淨壇使者

**總出現次數**:1985,**出場回數**:83 回

### 生平概述

豬八戒原為天庭[[豬八戒|天蓬元帥]]，掌管天河八萬水兵。因酒醉闖入廣寒宮糾纏[[嫦娥]]，被諸神拿住，經[[太白金星]]求情改刑貶下凡間。因錯投胎成為豬模樣，俗名[[豬八戒|豬剛鬣]]，在福陵山雲棧洞佔山為王，喫人度日。[[觀音]]菩薩點化後，豬八戒持齋把素，斷絕五葷三厭，專候取經人，並被賜法名[[豬八戒|豬悟能]]。

三年前，[[豬八戒|豬悟能]]被[[高太公]]招為女婿，初期勤謹耕田，後因相貌變異、食腸甚大而驚嚇高家，常被要求退親。[[唐僧]]與[[孫悟空]]路過高老莊，[[孫悟空]]變作女子誘惑並制服[[豬八戒|豬悟能]]。[[豬八戒|豬悟能]]得知[[唐僧]]身分後，跪地發誓皈依，拜[[唐僧]]為師，並被賜名[[豬八戒|八戒]]。隨後他燒毀雲棧洞，擔著行李，背了[[白龍馬]]，與師兄師弟一同辭別高老向西而去。

[[豬八戒]]一路護持[[唐僧]]西行，雖常有貪吃好色、懶惰怯戰之舉，亦多次參與降妖除魔。在歷經流沙河收服[[沙僧]]、火焰山借扇、比丘國救童等多次劫難後，最終抵達靈山。因一路挑擔有力、涉水有功，[[如來]]封其為[[豬八戒|淨壇使者]]，[[豬八戒]]因不滿未封成佛而有所怨言。

### 重要事蹟

*   **高老莊收徒**：被[[孫悟空]]制服後，向[[唐僧]]自述身世並拜師，被賜名[[豬八戒|八戒]]，隨後攜行李與師兄弟西行。（第18-19回）
*   **流沙河結義**：與[[沙僧]]大戰不分勝負，後由[[木吒]]引薦，[[沙僧]]皈依，[[豬八戒]]扶持[[唐僧]]渡過流沙河。（第22回）
*   **三打白骨精**：在[[白骨精]]變身事件中，[[豬八戒]][[孫悟空]]面前唆嘴，導致[[唐僧]]誤信並驅逐[[孫悟空]]。（第27回）
*   **智激美猴王**：[[唐僧]]被[[黃袍怪]]變為猛虎，[[白龍馬]]勸說[[豬八戒]]前往花果山請[[孫悟空]]出山，[[豬八戒]]以激將法成功請回[[孫悟空]]。（第30-31回）
*   **偷吃人參果**：在[[萬壽山]]五莊觀，[[豬八戒]]慫恿[[孫悟空]]偷摘人參果，事後被[[鎮元子]]懲罰鞭打。（第24-25回）
*   **三探無底洞**：[[豬八戒]]變作黑胖和尚跟隨妖精進入無底洞，並在洞口把守接應。（第82-83回）
*   **拱開稀柿衕**：在駝羅莊，[[豬八戒]]變做大豬，用長嘴和釘鈀拱開滿是糞便的稀柿衕道路，方便師徒通行。（第67回）
*   **大鬧金平府**：在[[金平府]]，[[豬八戒]]與[[孫悟空]]、[[沙僧]]共同對抗[[辟塵兒]]、[[辟暑兒]]、[[辟塵兒]]三隻[[犀牛精]]，並砍下其頭顱與角。（第92回）
*   **封淨壇使者**：取得真經後，[[如來]]因其挑擔有功，封為[[豬八戒|淨壇使者]]，[[豬八戒]]對此封號表示質疑。（第100回）
