# 黃風怪

**別名**:黃風大王

**總出現次數**:10,**出場回數**:5 回

### 生平概述

[[黃風怪]]原為靈山佛祖身邊的一隻黃毛貂鼠，後私自逃離靈山，佔據柳林坡解陽山下的貍嬰洞為王，自號黃風大王。他麾下有一虎先鋒與數十名小妖，長期盤踞在此地，意圖吞食長生肉以延年益壽。

當唐僧路經此地時，[[黃風怪]]派出的虎先鋒成功擒獲唐僧。[[黃風怪]]對唐僧的唐僧肉垂涎欲滴，但得知唐僧有神通廣大的徒弟護衛後，便採取緩兵之計，將唐僧綁在後園定風樁上，計劃待其徒弟疲憊或鬆懈時再行下手，並許諾若虎先鋒能捉拿孫行者便與其結拜兄弟。

隨後，[[黃風怪]]親自與[[孫悟空]]交戰，憑藉其三昧神風擊敗孫悟空並吹傷其雙眼。然而，他在戰鬥中不慎透露自身弱點，最終被趕來的[[靈吉菩薩]]用飛龍杖制服，現出黃毛貂鼠本相，隨即被押解回靈山受審。

### 重要事蹟

*   **擒獲唐僧**：允許部下虎先鋒擒獲唐僧，並將其綁於後園定風樁上暫存，以待時機。（第20回）
*   **策劃圍捕孫悟空**：承諾若虎先鋒能成功捉拿孫行者，便與其結拜為兄弟，試圖利用手下除掉強敵。（第20回）
*   **施展三昧神風**：在與[[孫悟空]]的正面交戰中，釋放三昧神風將孫悟空吹退並致其雙目受傷。（第21回）
*   **暴露弱點**：在戰鬥中高聲宣稱除了[[靈吉菩薩]]之外，自己無懼任何其他神兵利器，從而暴露了自身的克星。（第21回）
*   **被降伏現形**：在準備再次呼風對抗[[孫悟空]]時，被[[靈吉菩薩]]以飛龍杖制服，並顯露出黃毛貂鼠的本相。（第21回）
*   **被押送靈山**：被[[靈吉菩薩]]抓獲後，直接被帶往靈山接受懲罰。（第21回）

### 人物關係

*   **主僕**：虎先鋒（麾下猛將，曾執行擒拿唐僧任務）、眾小妖（洞府侍從）。
*   **對手**：[[孫悟空]]（多次交戰並被其激怒導致敗亡）、[[靈吉菩薩]]（最終將其降伏的神仙）。
*   **潛在獵物**：[[唐僧]]（被擒獲並綁縛，意圖食用）。
