# 哪吒

**別名**:哪吒太子

**總出現次數**:73,**出場回數**:15 回

### 生平概述

[[哪吒]]早年受[[玉皇大帝]]冊封為三壇海會大神，隨後奉命協助[[托塔李天王]]前往人間收服[[孫悟空]]。在花果山之戰中，[[哪吒]]與[[孫悟空]]交手數十回合未分勝負，最終因[[孫悟空]]使用分身法及毫毛誘敵而受傷敗退。此後，他持續參與天庭對[[孫悟空]]的圍剿行動，曾擔任前部先鋒率軍攻打花果山，並在[[二郎神]]圍捕[[孫悟空]]時，與[[托塔李天王]]共同擎舉照妖鏡協助作戰。

隨著[[孫悟空]]大鬧天宮，[[哪吒]]隨眾神前往靈山參加安天大會，並向[[如來]]捧獻明珠異寶。此後，[[哪吒]]多次奉旨下界執行任務，包括在南天門借用[[真武大帝]]的皂雕旗協助[[孫悟空]]設局騙過妖怪，以及奉[[玉皇大帝]]金旨與[[孫悟空]]一同下界擒拿兕怪。在下界征戰期間，[[哪吒]]展現了變身三頭六臂、手持六般兵器的戰鬥能力，但也曾因兵器被妖怪圈子套去而陷入困境。

晚年時期，[[哪吒]]繼續聽從[[玉皇大帝]]旨意，與[[托塔李天王]]聯手攔截並擒獲[[牛魔王]]，以及在陷空山無底洞收降[[老鼠精]]。在處理[[老鼠精]]一事上，[[哪吒]]曾誤認該妖為其胞姐，經[[托塔李天王]]欲殺妖時出面阻擋，並在得知真相後向[[孫悟空]]求情，最終依[[如來]]之命饒恕該妖性命並將其捆綁歸案。

### 重要事蹟

*   **第4回**：被[[玉皇大帝]]封為三壇海會大神，隨[[托塔李天王]]下界收伏[[孫悟空]]；與[[孫悟空]]交戰三十回合不分勝負，遭[[孫悟空]]用毫毛變身誘敵並打傷左膊，敗陣而回；向[[托塔李天王]]報告[[孫悟空]]神通廣大且要求封為齊天大聖，建議暫不與之相持。
*   **第5回**：被[[玉皇大帝]]任命為前部先鋒，率領天兵天將下界圍困花果山；與[[孫悟空]]在半空中大戰，最終被[[孫悟空]]使用分身法打退。
*   **第6回**：與[[托塔李天王]]共同擎著照妖鏡，立在空中協助[[二郎神]]圍困[[孫悟空]]；在灌江口附近與[[托塔李天王]]一起被[[二郎神]]詢問是否看見[[孫悟空]]。
*   **第7回**：出席安天大會，捧著明珠異寶向[[如來]]拜獻。
*   **第17回**：曾率兵征討[[孫悟空]]並負痛逃離。
*   **第33回**：向[[玉皇大帝]]奏請借來[[真武大帝]]的皂雕旗，在南天門展開以遮蔽日月星辰，協助[[孫悟空]]騙過妖怪；奉旨完成任務後，回宮繳旨並將皂雕旗送還[[真武大帝]]。
*   **第42回**：奉父王[[托塔李天王]]之命，取出三十六把天罡刀遞給[[木吒]]。
*   **第51回**：奉[[玉皇大帝]]金旨與[[孫悟空]]一同下界擒拿兕怪；在洞口與魔王交戰，變作三頭六臂手持六般兵器攻擊魔王；將六般兵器拋出變作千百件兵器攻擊魔王，但被魔王用圈子全部套去；因兵器被套而赤手逃生，隨後與[[托塔李天王]]等在天上南坡下懊惱；對[[孫悟空]]在眾人敗陣時發笑表示憤怒；觀戰[[孫悟空]]與魔王打拳，並對[[孫悟空]]的分身法表示讚賞。
*   **第52回**：與[[托塔李天王]]等眾神協助[[孫悟空]]對抗兕大王；[[孫悟空]]變作小猴盜取火部兵器後，[[哪吒]]收走了六件兵器；與火德星君等將神兵拋向妖魔，但被兕大王用圈子盡數撈去；戰敗後，與眾神回到高峰，對[[孫悟空]]表示無奈；最後[[孫悟空]]擊敗兕大王後，與[[托塔李天王]]等眾神返回天庭。
*   **第61回**：奉[[玉皇大帝]]旨意，與[[托塔李天王]]率領魚肚藥叉、[[巨靈神]]將攔截[[牛魔王]]；變作三頭六臂，飛身跳到牛王背上斬下其頭，但牛王頭落復生；將火輪掛在牛王角上吹真火，燒得牛王張狂哮吼無法變化脫身；[[托塔李天王]]用照妖鏡照住牛王本象後，用縛妖索穿住牛王鼻孔將其擒獲。
*   **第81回**：其同胞姐妹被揭示為本回中變身女子、攝走[[唐僧]]的[[老鼠精]]。
*   **第83回**：用斬腰劍架住[[托塔李天王]]砍向[[孫悟空]]的刀，並叩頭告知父親下界妖精是其結拜恩女而非親妹；奉[[如來]]之命與父親[[托塔李天王]]收降偷食香花寶燭的金鼻白毛[[老鼠精]]，並因[[如來]]吩咐饒其性命；隨父親[[托塔李天王]]率領天兵神將下界降妖，最終在陷空山無底洞搜出並捆綁[[老鼠精]]；向[[孫悟空]]磕頭求命，並下令天兵取下縛妖索捆綁所有妖精。

### 人物關係

*   **主僕/上下級**：[[玉皇大帝]]（受其冊封及命令）、[[托塔李天王]]（父親及統帥）
*   **同盟/合作**：[[二郎神]]（共同圍困[[孫悟空]]）、[[木吒]]（遞送天罡刀）、[[巨靈神]]（共同攔截[[牛魔王]]）、[[火德星君]]（共同攻擊妖魔）
*   **對手**：[[孫悟空]]（多次交戰）、[[牛魔王]]（被其擒獲）、[[老鼠精]]（收降對象）
*   **親屬**：[[托塔李天王]]（父親）、[[老鼠精]]（曾被誤認為同胞姐妹，實為結拜恩女）
